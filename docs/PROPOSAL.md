# 参赛项目说明

**项目名称：MoonFileCheck——面向编译器、代码生成器与 CLI 的 MoonBit 原生文本回归测试工具。**

方向：开发者工具。

开发者维护编译器、生成器或 CLI 时，需要持续确认输出中的关键行为是否正确。精确锁定所有输出会把无关变化也纳入测试；只查找一个字符串又无法验证顺序、变量定义/使用和禁止出现的内容。本项目提供可嵌入源码注释的模式约束，用于表达这些要求。

以 Bytecode Alliance filecheck 0.5.0 为语义基线，用 MoonBit 实现六类指令、捕获变量及复用、无序依赖、否定区间和结构化诊断。核心库可在 JS、wasm-gc、native 使用，CLI 使用薄 Node 宿主执行文件输入和隔离，核心匹配不委托给 Rust/JavaScript。

开发中独立发现并修复：正则依赖的 UTF-16 低代理项边界崩溃，以及本项目模式归一化丢失补充平面字符导致误通过的问题。两类问题均保留回归检查。验证同时使用固定上游语料、独立边界用例、实际 Rust 差分和三后端测试，详细结果见 VALIDATION.md。

演示依次展示寄存器重命名通过、寄存器不一致失败、中文与 emoji 输入、工具链生成的两个真实接口文件检查。接口示例证明可接入工具输出，没有声称第三方用户采用。

原创工作、移植来源和生成数据分别在 THIRD_PARTY.md 中记录。当前明确未覆盖完整 LLVM FileCheck、完整 Rust regex 语义和原生独立 CLI。未执行报名、官方验收；本说明可在用户审核后用于申报。
